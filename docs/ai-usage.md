# AI 활용 및 고도화

## 1. 활용한 AI 도구

칭찬고래 개발 과정에서는 ChatGPT 계열 생성형 AI를 보조 도구로 활용했습니다. AI는 기획 아이디어를 구체화하고, React Native·Expo 코드의 초안을 작성하며, 오류 원인 분석·문서 작성·사용자 시나리오 정리에 활용했습니다. AI가 작성한 결과물을 그대로 제품에 반영하지 않고 팀원이 프로젝트 구조와 요구사항에 맞게 검토·수정했습니다.

## 2. AI 활용 범위

### 개발 보조

- 화면 컴포넌트와 스타일의 초안 작성
- TypeScript 타입 및 React Native API 사용 예시 확인
- 키보드·스크롤·권한 처리와 같은 플랫폼별 동작의 원인 분석
- 린트 오류와 예외 상황을 재현하고 수정 방향을 검토

### 서비스 기능

칭찬고래의 핵심 AI 기능은 사용자가 작성한 하루 기록에서 실제로 해낸 행동을 찾아 긍정적인 관점으로 다시 바라보도록 돕는 것입니다. 단순한 “잘했어요”가 아니라 기록의 구체적인 행동과 맥락을 반영한 칭찬을 생성하는 것을 목표로 합니다. 또한 과거 기록과 축제에서 수집한 칭찬 데이터의 표현을 참고해 사용자에게 더 자연스럽고 개인화된 답변을 제공하도록 고도화하고 있습니다.

현재 모바일 저장소에서는 AI 응답 UI와 적용 흐름을 구현하고, 화면 검증을 위해 샘플 응답을 사용합니다(`src/pages/write/index.tsx`의 `SAMPLE_RESPONSES`). 실제 생성·검색·안전성 처리는 별도 AI 서버와 연동하는 구조로 분리하여 API 키가 모바일 앱에 노출되지 않도록 했습니다.

## 3. AI 생성 코드의 검증 및 수정 방식

AI가 제안한 코드는 다음 절차로 검증했습니다.

1. 프로젝트의 Expo SDK, React Native 버전과 기존 코드 스타일에 맞는지 확인했습니다.
2. 변경 범위를 작은 단위로 나누고 실제 Android·iOS 개발 환경에서 실행했습니다.
3. 린트와 TypeScript 오류를 확인하고, 화면 전환·키보드·권한·이미지 선택 등 주요 사용자 흐름을 직접 테스트했습니다.
4. 플랫폼별 차이가 있는 기능은 Android와 iOS에서 각각 재현해 결과를 비교했습니다.
5. 보안과 개인정보 관점에서 API 키, 사용자 일기, 이미지가 클라이언트 코드에 불필요하게 노출되지 않는지 확인했습니다.
6. 오류가 발생한 코드는 AI 답변을 그대로 유지하지 않고 원인을 직접 확인한 뒤 프로젝트에 맞게 수정했습니다.

특히 AI 답변은 사실 여부와 안전성을 자동으로 보장하지 않으므로, 서비스 기능으로 적용할 때는 입력 검증, 부적절한 표현 필터링, 실패 시 대체 응답, 사용자에게 전문적인 상담을 대신하지 않는다는 안내를 함께 적용합니다. AI는 정신건강 진단이나 치료를 제공하지 않으며, 위험 신호가 포함된 입력은 별도의 안전 정책에 따라 처리합니다.

## 4. 향후 고도화 계획

- 일기와 관련된 과거 기록·칭찬 예시를 검색하는 개인화 기능 개선
- 실제 사용자 표현을 반영한 프롬프트와 평가 데이터셋 구축
- 부적절하거나 과도하게 단정적인 답변을 줄이기 위한 안전성 평가
- 답변 품질, 응답 지연 시간, 사용자 재작성률을 기준으로 한 지속적인 검증
- AI 사용 비용과 개인정보 보관 범위를 최소화하는 서버 구조 개선
