## 1. 프로젝트 배경

### 1.1 국내외 (시장) 현황 및 문제점

현대 Z세대는 SNS 피로감과 자기 비판적 사고 패턴으로 인한 정서적 소진을 호소하는 비율이 증가하고 있다. 기존 SNS(인스타그램, X 등)는 '잘 보이기 위한 퍼포먼스'를 요구하며, 비교와 경쟁의 심리를 심화시킨다. 반면 심리 치유 앱들은 전문 상담 영역에 가깝거나 혼자 쓰는 일기 형식으로, 친구와 자연스럽게 긍정 감정을 나누는 소셜 경험을 제공하지 못한다.

또한 자기 자신을 칭찬하는 습관이 자기효능감과 정서적 회복력에 유의미한 영향을 미친다는 심리학적 연구가 다수 존재하나, 이를 일상의 SNS 습관으로 연결한 서비스는 아직 국내외에 부재하다.

### 1.2 필요성과 기대효과

- **자기 칭찬 습관화**: 하루 한 번 자신을 칭찬하는 기록이 자기 인식을 긍정적으로 전환
- **칭찬 능력 향상**: 친구의 글에 댓글을 달며 자연스럽게 타인 칭찬 표현력 성장
- **긍정적 소셜 환경 조성**: 비교·과시 없이 서로를 응원하는 관계 중심 커뮤니티 형성
- **AI 활용 정서 지원**: 부정적 하루도 AI가 긍정 포인트를 발견해 재구성, 심리적 진입 장벽 낮춤

| 1. 사용자 입력 | 일기 원문 수신 |
| 2. 안전 검수 | NLP 분류 모델 + 키워드 규칙 이중 검수로 위기 신호 진단 (위험 감지 시 후속 단계 전면 차단) |
| 3. 메모리 저장 | GPT 기반 Memory Extraction으로 핵심 사실·감정·행동 패턴을 구조화 저장, 텍스트 임베딩 + 다차원 감정 벡터를 pgvector에 저장 |
| 4. 메모리 검색 | **Module A — Temporal Decay Reranking**: 시간 감쇠 함수로 최근 경험 가중 / **Module B — Emotion-Aware Retrieval**: 텍스트 유사도 + 감정 유사도 복합 점수 검색 |
| 5. 컨텍스트 구성 | **Module C — Adaptive Prompt Assembly**: 기억 유무와 감정 강도에 따라 4가지 전략(COLD_START / EMPATHY_FIRST / PATTERN_CONNECT / GROWTH_REFLECT) 동적 선택 |
| 6. LLM 응답 생성 | GPT-4o-mini로 기억·선호 어조가 반영된 개인화 재구성 생성 |
| 7. Self-Inspection | CoT 기반 자가 검수 (감정 인정 여부, 과도한 긍정·비꼼 여부), 미달 시 자동 재생성 + 사용자 '다른 한마디'(최대 3회) 제공 |

#### ○ 위기 신호 감지 — 전문기관 연계 및 오작동 대응 프로토콜 (기술 심화)

**(1) 위험도 단계별 대응 체계**

NLP 분류 모델과 키워드 규칙의 이중 검수 결과를 4단계 위험도로 분류하고, 단계별로 차등 대응한다.

| 단계 | 판정 | 대응 |
|---|---|---|
| Lv0. 안전 | 위기 신호 없음 | 정상 파이프라인 진행 |
| Lv1. 주의 | 강한 부정 감정 (위기 아님) | EMPATHY_FIRST 전략 사용 (칭찬 최소화, 공감 우선 응답) |
| Lv2. 위험 | 자해 및 자살 관련 표현 감지 | AI 재구성 중단 → 위로 메시지 + 전문기관 안내 카드 표시 |
| Lv3. 긴급 | 구체적 위해 계획 및 임박 신호 | 위기 대응 모드 전환 (상담 전화 원터치 연결 버튼 우선 노출) |

**(2) 전문기관 연계 방안**

- **자살예방 상담전화 109**: 위기 안내 카드에서 원터치 전화 연결
- **정신건강 위기상담 1577-0199, 청소년 전화 1388**: 사용자 연령·상황에 맞춰 함께 안내
- **부산대학교 학생상담센터**: 1차 사용자가 학내 구성원인 점을 활용, 교내 대면 상담 경로를 앱 내 안내 (출시 전 센터와 안내 문구·연계 절차 협의 예정)
- 안내 카드는 비낙인적 문구로 설계하여 사용자가 거부감 없이 도움을 받을 수 있도록 한다 (예: "오늘 많이 힘들었던 것 같아요. 이야기를 들어줄 수 있는 곳을 알려드릴게요")

**(3) 오작동 대응 프로토콜**

위기 감지 시스템은 과탐(False Positive)과 미탐(False Negative)이 모두 발생할 수 있으며, 미탐의 비용이 훨씬 크다는 원칙 하에 다음과 같이 운영한다.

**과탐(위기가 아닌데 차단) 대응:**
- 위기 모드에서도 일기 작성·게시 자체는 차단하지 않고, AI 재구성 기능만 안전 안내로 대체 → 오탐이 사용자 경험 전체를 막지 않도록 설계
- 안내 카드에 "괜찮아요, 계속 쓸게요" 피드백 버튼 제공 → 오탐 피드백을 익명화 수집하여 키워드 규칙 정밀화 및 분류 임계값 보정에 활용

**미탐(위기인데 통과) 대응:**
- 분류 임계값을 재현율(Recall) 우선으로 보수적으로 설정 — 애매한 경우 안전 측으로 판정
- NLP 모델이 놓친 경우를 대비한 키워드 규칙 안전망 상시 가동 (이중 검수의 목적)

**운영 모니터링:**
- 위기 감지 로그를 PII 익명화하여 저장하고, 월 단위로 Precision/Recall을 평가하는 검증 데이터셋 운영
- 베타 기간 중 오작동 사례를 수집하여 출시 전 임계값·규칙 셋 확정

### 2.2 기존 서비스 대비 차별성

| 비교 대상 | 유사한 점 | 칭찬고래의 차별점 |
|---|---|---|
| 인스타그램 스토리 | 일상을 친구들과 가볍게 공유하는 구조 | 사진이 아닌 글 중심으로, 오늘의 나를 언어로 직접 표현하게 만든다. 이 과정 자체가 자기 긍정의 훈련이 된다 |
| X (트위터) | 짧고 솔직한 일상을 공유하는 형식 | 솔직함과 반응이 목적인 X와 달리, 칭찬과 응원만 허용되는 댓글 문화를 구조적으로 내장해 긍정의 선순환을 만든다 |
| Day One 등 일기 앱 | 오늘의 나를 짧게 기록하는 경험 | 혼자 쓰고 끝나지 않는다. 친구가 반응해주는 소셜 경험이 더해져 기록의 동기와 지속성이 확연히 달라진다 |
| 밴드 | 지인 기반 폐쇄형 커뮤니티 구조 | 공지·자료 공유 중심인 밴드와 달리, 20대를 타깃으로 '칭찬'이라는 명확한 콘텐츠 컨셉을 중심에 둔다 |
| 블로그 | 글을 쓰고 공유하는 공간 | 400자 이내로 제한해 진입 장벽을 낮춘다. 잘 쓴 글이 아니어도, 완성된 생각이 아니어도 된다 |
| 감정 일기앱 (하루콩, 무디 등) | 감정을 기록하고 돌아보는 경험 | 이모지 선택형 단발 기록과 달리, ① 글 기반 자기 칭찬으로 능동적 자기 긍정 훈련을 유도하고 ② AI가 과거 감정 패턴 메모리를 기반으로 시간 축 개인화 응답("그때랑 지금이 달라졌어요")을 제공하며 ③ 친구 응원이라는 소셜 동기로 기록 지속성을 만든다 |
| AI 심리 케어 챗봇 (소울메이트형 서비스 등) | AI가 감정에 공감하고 응답 | 대화가 목적이 아니라 기록 → 재구성 → 친구 응원으로 이어지는 소셜 루프의 한 단계로 AI를 배치함으로써 AI 의존이 아니라 실제 관계 강화가 목표이며, 위기 시 AI 응답을 중단하고 전문기관으로 연결하는 안전 설계를 기본 탑재 |

**기술적 차별성 — 감정 인지 메모리 시스템:**
기존 감정 기록 앱의 AI 기능은 당일 입력만을 보는 단발성 응답에 그친다. 칭찬고래는 pgvector 기반 장기 기억 저장소 위에 Temporal Decay Reranking(시간 감쇠 가중), Emotion-Aware Retrieval(감정 벡터 복합 검색), Adaptive Prompt Assembly(기억·감정 상태별 응답 전략 분기)를 자체 설계하여, 사용할수록 사용자를 더 깊이 이해하는 구조를 갖는다. 이 누적 개인화는 차별성인 동시에 전환 비용(switching cost)으로 작동하여 지속 사용의 기술적 기반이 된다.

## 3. 활용 방안

### 3.1 활용 계획

**사회적 활용 — 대학 커뮤니티 및 청년 정서 지원**

칭찬고래는 부산대학교 재학생을 1차 사용자로 출시하여 학내 커뮤니티에서의 실사용 데이터를 확보한다. 자기 비판적 사고와 SNS 피로감이 심각한 20대 초반 대학생층에게 긍정적 자기 서사 훈련 도구로 활용될 수 있으며, 중장기적으로는 정서 지원이 필요한 청소년 및 시니어 계층으로 확장을 검토한다.

**상용화 계획**

- **MVP (2026년 6~8월)**: 학내 100명 이상 대상 클로즈드 베타 운영, 핵심 지표(D7 리텐션 30%, 댓글 달린 글 비율 50%) 검증, 베타에서 알림 빈도 및 스트릭 보상 등 참여 장치 A/B 검증
- **v1 정식 출시 (2026년 하반기)**: App Store / Google Play 배포, 친구 초대 기반 바이럴 그로스
- **v2 (2027년)**: AI 분석 리포트, 칭찬 카드 공유 기능, 수익화 모델(프리미엄 기능) 도입

**수익 모델 (검토 중)**

- 프리미엄 AI 분석 리포트 구독
- 특수 스티커·이모지 팩 인앱결제
